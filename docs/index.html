Install in 10 seconds

Inside Claude Code (desktop, CLI or web), run:

/plugin marketplace add kaazyxx/ultimate-dev-toolkit
/plugin install ultimate-dev-toolkit

Then run /udt:doctor to see exactly which tools and skills are live in your environment.

What you get

520 skills

Auto-loading expertise across 70+ languages, every major framework, databases, DevOps, security, data/ML, AI/LLM, game & graphics, web3, embedded and more.

176 slash commands

Namespaced, ready-to-run workflows: /git:*, /db:*, /security:*, /qa:*, /ai:*, /k8s:*, and dozens more.

120 specialist agents

Per-language reviewers, build-resolvers and auditors — security, performance, data-quality, LLM guardrails, resilience and beyond.

28 safety hooks

Advisory, never-block-by-default guards for destructive commands and secret writes, plus an audit trail and SessionStart auto-update.

4 MCP connectors

sequential-thinking · memory · filesystem · blender — wired in through the plugin manifest.

Honest by design

Never claims a tool is supported unless it is actually detected. Real, functional entries over fake ones.
