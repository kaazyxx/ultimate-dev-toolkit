---
description: "Profile a dataset: schema, stats, missingness, quality."
argument-hint: "<file>"
allowed-tools: Read, Bash
---

Profile the dataset in $ARGUMENTS using the `data-science-eda`/`data-cleaning` skills. Report schema/dtypes, row/column counts, missingness, distributions and obvious quality issues (duplicates, outliers, encoding). Flag anything that would break downstream modeling.
