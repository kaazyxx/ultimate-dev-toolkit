Give a clear git status using the `git-workflows`/`git-advanced` skills.

Run `git status`, `git branch --show-current`, and `git log --oneline -10`. Summarize staged vs unstaged changes, the current branch's relation to its upstream, and anything unusual (detached HEAD, conflicts, untracked build artifacts).
