# Algorithms Data Structures

**Category:** architecture

## Checklist

- Complexity analyzed (time/space)
- Data structure fits access pattern
- Edge cases handled

## Common pitfalls

- Accidental O(n^2) on large inputs
- Wrong structure for the operation
- Premature optimization of non-hotspots
