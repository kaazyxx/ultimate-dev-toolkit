# Requirements Analysis

**Category:** quality

## Checklist

- Acceptance criteria explicit
- Edge cases and non-functionals captured
- Ambiguities resolved with the requester

## Common pitfalls

- Building the wrong thing from vague specs
- Ignoring non-functional requirements
- Gold-plating beyond the need
