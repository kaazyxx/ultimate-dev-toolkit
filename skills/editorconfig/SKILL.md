# Editorconfig

**Category:** tooling

## Checklist

- .editorconfig committed at repo root
- Line endings and charset set (LF, utf-8)
- Editors configured to respect it

## Common pitfalls

- CRLF/LF churn across OSes
- Mixed indentation without a shared config
