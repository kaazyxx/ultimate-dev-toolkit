# Data Privacy

**Category:** quality

## Checklist

- Collect only what's needed (minimization)
- Retention/deletion policy enforced
- PII encrypted and access-controlled

## Common pitfalls

- Collecting/keeping data with no purpose
- PII in logs/analytics
- No deletion path for subject requests
