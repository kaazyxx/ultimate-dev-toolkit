# Security Iam

**Category:** security

## Checklist

- Least privilege per role
- Temporary over long-lived credentials
- Regular access review/deprovisioning

## Common pitfalls

- Wildcard (*) permissions
- Long-lived static keys
- Privilege creep with no review
