# Web Scraping Legal

**Category:** automation

## Checklist

- robots.txt and ToS respected
- Rate-limited and identified (User-Agent)
- Only public data; no CAPTCHA/auth bypass

## Common pitfalls

- Ignoring robots.txt/ToS
- Hammering servers (no rate limit)
- Scraping personal/paywalled data
