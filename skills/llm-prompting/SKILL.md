# Llm Prompting

**Category:** data-ml

## Checklist

- Instructions explicit and testable
- Output format constrained/validated
- Prompts evaluated on real cases

## Common pitfalls

- Vague prompts with no output contract
- No evaluation of prompt changes
- Prompt injection from untrusted input
