# Design Systems

**Category:** design

## Checklist

- Tokens for color/spacing/type
- Reusable, documented components
- Theming (light/dark) supported

## Common pitfalls

- One-off styles diverging from the system
- Undocumented components
- Hardcoded values instead of tokens
