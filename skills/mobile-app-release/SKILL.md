# Mobile App Release

**Category:** platforms

## Checklist

- Signing/certs and version bump correct
- Store guidelines and privacy labels met
- Staged rollout with crash monitoring

## Common pitfalls

- Rejections from missing privacy disclosures
- No staged rollout (bad build to everyone)
- Signing key mismanagement
