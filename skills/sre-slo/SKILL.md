# Sre Slo

**Category:** devops

## Checklist

- SLIs measure user-facing reliability
- Error budget drives release decisions
- Alerts fire on SLO burn, not raw metrics

## Common pitfalls

- Alerting on causes instead of symptoms
- 100% uptime targets (no budget for change)
