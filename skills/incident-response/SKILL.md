# Incident Response

**Category:** devops

## Checklist

- Mitigate first, root-cause later
- Clear incident commander and comms
- Blameless postmortem with action items

## Common pitfalls

- Debugging in prod before mitigating impact
- No communication to stakeholders
- Postmortems that blame people
