# Tdd Workflow

**Category:** testing

## Checklist

- Failing test written first (red)
- Minimal code to pass (green)
- Refactor with tests green

## Common pitfalls

- Writing tests after (not TDD)
- Testing implementation, not behavior
- Skipping the refactor step
