# Architecture Patterns

**Category:** architecture

## Checklist

- Pattern justified by real constraints
- Coupling/cohesion considered
- Simplest thing that could work chosen

## Common pitfalls

- Microservices for a small team/app
- Cargo-culting patterns without need
- Premature distributed complexity
