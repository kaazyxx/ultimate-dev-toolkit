# Security Threat Modeling

**Category:** security

## Checklist

- Assets and trust boundaries mapped
- Threats enumerated (STRIDE)
- Mitigations prioritized by risk

## Common pitfalls

- Security as an afterthought post-design
- Modeling threats but never mitigating
