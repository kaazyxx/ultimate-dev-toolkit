# Functional Programming

**Category:** architecture

## Checklist

- Pure core; side effects at the edges
- Immutability by default
- Composition over imperative mutation

## Common pitfalls

- Point-free code that's unreadable
- Hidden effects in 'pure' functions
- Over-abstraction with monad stacks

- `haskell`
