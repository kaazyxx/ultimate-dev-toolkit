# Security Compliance

**Category:** security

## Checklist

- Controls mapped to requirements
- Data classification and retention defined
- Evidence collection automated where possible

## Common pitfalls

- Checkbox compliance without real security
- Undefined data retention/deletion
- Manual evidence that rots
