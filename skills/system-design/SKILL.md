# System Design

**Category:** architecture

## Checklist

- Functional + non-functional requirements clear
- Bottlenecks and failure modes identified
- Tradeoffs stated explicitly

## Common pitfalls

- Designing for scale you'll never hit
- Ignoring failure modes
- No capacity estimation
