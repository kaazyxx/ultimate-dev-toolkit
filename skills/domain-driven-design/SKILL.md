# Domain Driven Design

**Category:** architecture

## Checklist

- Ubiquitous language shared with domain experts
- Bounded contexts explicit
- Aggregates guard invariants

## Common pitfalls

- DDD ceremony on a CRUD app
- Anemic domain model
- Leaky bounded contexts
