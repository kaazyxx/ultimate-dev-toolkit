# Cloud Migration

**Category:** platforms

## Checklist

- Migration strategy per app (rehost/replatform/refactor)
- Data migration validated
- Rollback/cutover plan

## Common pitfalls

- Big-bang cutover with no rollback
- Underestimating data transfer time/cost
- Lift-and-shift without cost review
