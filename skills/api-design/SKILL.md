# Api Design

**Category:** architecture

## Checklist

- Consistent naming and error shapes
- Backward compatibility / versioning plan
- Pagination and filtering for collections

## Common pitfalls

- Breaking changes without versioning
- Leaking internal models as the contract
- Inconsistent conventions across endpoints
