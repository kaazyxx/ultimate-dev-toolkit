# Web Frontend Remix

**Category:** web  ·  **Requires (detect first):** npm

## Required tools & detection

Before acting, confirm these are installed (see the `environment-detection` skill). If a tool is missing, say so and suggest how to install it — never pretend it is present.

## Key commands

```bash
npm run dev
npm run build
```

## Checklist

- Loaders/actions handle errors
- Forms work without JS (progressive enhancement)
- Data revalidation correct

## Common pitfalls

- Fetching in components instead of loaders
- Not handling action validation errors
