# Observability Logging

**Category:** devops

## Checklist

- Structured JSON logs with correlation ids
- Retention and index lifecycle set
- No secrets/PII in logs

## Common pitfalls

- Unstructured free-text logs
- Logging secrets
- Unbounded retention costs
