# Oop Principles

**Category:** architecture

## Checklist

- Composition preferred over deep inheritance
- Single responsibility per unit
- Dependencies inverted at boundaries

## Common pitfalls

- Deep inheritance hierarchies
- God objects
- SOLID as dogma over pragmatism
