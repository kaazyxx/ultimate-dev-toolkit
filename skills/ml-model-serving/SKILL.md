# Ml Model Serving

**Category:** data-ml

## Checklist

- Input validation and versioned models
- Latency/throughput measured
- Drift/performance monitored

## Common pitfalls

- Train/serve skew in preprocessing
- No model versioning/rollback
- No monitoring for drift
