# Cloud Storage

**Category:** platforms

## Checklist

- Encryption at rest enabled
- Access private by default
- Lifecycle policies for cost/retention

## Common pitfalls

- Public buckets
- No lifecycle (cost creep)
- Wrong storage class for access pattern
