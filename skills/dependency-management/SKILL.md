# Dependency Management

**Category:** tooling

## Checklist

- Automated update PRs (renovate/dependabot)
- Upgrades tested before merge
- Unused deps removed

## Common pitfalls

- Dependency sprawl and bloat
- Never upgrading (security debt)
- Adding a library for a one-liner
