# Llm Rag

**Category:** data-ml

## Checklist

- Chunking suits the content/query
- Retrieval quality measured (recall@k)
- Answers grounded/cited from context

## Common pitfalls

- Poor chunking hurting retrieval
- No retrieval evaluation
- Hallucination from ungrounded context
