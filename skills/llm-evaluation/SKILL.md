# Llm Evaluation

**Category:** data-ml

## Checklist

- Golden/eval set representative of real use
- Automated regression on prompt/model changes
- Judge bias accounted for

## Common pitfalls

- Vibe-checking instead of measuring
- Overtrusting LLM-as-judge without calibration
- No regression suite on changes
