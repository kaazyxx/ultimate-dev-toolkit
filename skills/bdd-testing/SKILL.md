# Bdd Testing

**Category:** testing

## Checklist

- Scenarios in ubiquitous language
- Given-When-Then structure
- Scenarios executable and maintained

## Common pitfalls

- Brittle step definitions
- Scenarios that test UI details, not behavior
- BDD ceremony without stakeholder buy-in
