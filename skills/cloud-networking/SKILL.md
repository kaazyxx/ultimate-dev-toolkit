# Cloud Networking

**Category:** platforms

## Checklist

- Private subnets for data tiers
- Security groups least-exposure
- Private endpoints over public where possible

## Common pitfalls

- Databases in public subnets
- Overly open security groups
- DNS/routing misconfig causing outages
