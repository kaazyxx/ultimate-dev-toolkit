# Ab Testing

**Category:** quality

## Checklist

- Hypothesis and success metric predefined
- Sample size/power calculated
- No peeking; run to completion

## Common pitfalls

- Stopping early on a lucky result (peeking)
- Underpowered tests
- Ignoring guardrail metrics
