# Ml Experiment Tracking

**Category:** data-ml

## Checklist

- Params/metrics/artifacts logged per run
- Runs comparable and reproducible
- Best run promotable to registry

## Common pitfalls

- Untracked runs you cannot reproduce
- Logging metrics but not the code/data version
