# Security Forensics

**Category:** security

## Checklist

- Evidence preserved (don't destroy it)
- Timeline and IOCs documented
- Containment scoped before cleanup

## Common pitfalls

- Rebooting/wiping before capturing evidence
- Incomplete scoping missing persistence
