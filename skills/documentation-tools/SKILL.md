# Documentation Tools

**Category:** tooling

## Key commands

```bash
npx typedoc
cargo doc
mkdocs build
```

## Checklist

- Docs generated from source of truth
- Examples compile/run
- Published/versioned

## Common pitfalls

- Hand-maintained docs drifting from code
- Broken examples
- Undocumented public APIs
