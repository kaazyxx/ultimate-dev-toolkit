# Versioning Semver

**Category:** tooling

## Checklist

- Breaking changes bump major
- Deprecations before removal
- Version reflects real compatibility

## Common pitfalls

- Breaking changes in a minor/patch
- 0.x used forever to avoid discipline
- No deprecation window
