# Nft Metadata

**Category:** web3

## Checklist

- Metadata pinned/immutable (IPFS/Arweave)
- Standard-compliant tokenURI/JSON
- No mutable centralized metadata unless intended

## Common pitfalls

- Metadata on a server that can vanish
- Non-standard JSON breaking marketplaces
- Broken IPFS pinning
